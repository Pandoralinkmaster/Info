# PandoraOS Masterplan

## Ziel
Ein maximales Zwei-Geräte-System:
1. Android-Handy als PandoraOS Mobile
2. Raspberry Pi 5 als einziger CEO-Core

## Handy
- JayJay UI
- Voice Service
- Kamera/Sensoren
- lokale Befehle
- lokale Room-Datenbank
- jayjay_memory.json
- verschlüsselte Verbindung zum Pi

## Raspberry Pi 5 CEO-Core
- Hauptdatenbank
- JayJay Master Memory
- OpenAI/Ollama Gateway
- API Server
- Web Dashboard
- Backup Server
- Security Engine
- Network Intelligence
- QuantumKeyServer
- ComputeMeshManager reduziert auf 1 CEO-Node

## Verbindung
- WireGuard VPN
- HTTPS API
- Token Auth
- verschlüsselte Memory-Synchronisation

## Anpassung
Mesh bleibt vorhanden, aber nur:
Handy <-> Raspberry Pi 5

Keine vielen Nodes.
Kein großes Cluster.
Der Raspberry Pi 5 ist Master.
Das Handy ist Client + Sensor + Bedienung.
